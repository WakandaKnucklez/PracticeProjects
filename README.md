# Number Guessing Game

A Python-based number guessing game where players try to guess a randomly generated number between **1 and 100**. The game features three difficulty levels, each with a different number of attempts and its own high-score system.

## Difficulty Levels

- **Easy:** 10 attempts
- **Medium:** 5 attempts
- **Hard:** 3 attempts

## Features

- Random number generation (1–100).
- Three difficulty levels.
- Different attempt limits for each difficulty.
- Hints indicating whether your guess is too high or too low.
- Separate high scores for each difficulty.
- Input validation.
- Replay functionality.

## Objective

Guess the randomly generated number before running out of attempts. Challenge yourself with harder difficulties and try to beat your high scores!

## Technologies Used

- Python

## Purpose

Created as a programming practice project to improve my Python skills, particularly with loops, conditional statements, functions, and input handling.
