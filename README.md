# Task Tracker CLI

A lightweight task management application built with Python, designed to help organize tasks and keep track of progress through a simple command-line interface.

## What It Can Do

- **Task Management:** Add new tasks to your personal task list.
- **Editing:** Update task descriptions whenever plans change.
- **Deletion:** Remove tasks that are no longer needed.
- **Progress Tracking:** Change task statuses to reflect their current state.
- **Update Tracking:** Keep a record of when each task was last modified.
- **Persistent Data:** Store task information in a JSON file, allowing it to be loaded again when the application is reopened.

## Under the Hood

The project uses Python's built-in libraries to handle data storage and date tracking.

| Technology | Usage |
|---|---|
| Python | Main programming language |
| JSON | Task data storage |
| Datetime | Update date tracking |

## Getting Started

Run the application from your terminal:

```bash
python TaskTracker.py
```

Make sure `TaskData.json` is in the project directory.
